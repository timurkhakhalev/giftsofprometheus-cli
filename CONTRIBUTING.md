# Contributing

Thank you for your interest in the Gifts of Prometheus CLI.

## Pull requests

The repository does not accept pull requests. The CLI follows an API that changes together with the service, so all changes are made by the maintainer. Pull requests are disabled.

## Issues and ideas

- **Bugs:** open an [issue](https://github.com/timurkhakhalev/giftsofprometheus-cli/issues/new/choose) with the CLI version (`giftsofprometheus --version`), the command, what you expected and what happened. Run the command with `--json` and include the output, but remove anything personal.
- **Ideas and questions:** start a [discussion](https://github.com/timurkhakhalev/giftsofprometheus-cli/discussions).
- **Problems with the catalog itself** (a wrong summary, a missing talk): open an issue too; it reaches the same maintainer.
- **Vulnerabilities:** do not open a public issue, follow [SECURITY.md](SECURITY.md).
